# Language Performance Comparisons

Benchmarks of the same tasks across Dart, Go, Java, JavaScript, PHP, Python, Ruby, Rust, TypeScript and Mojo.

## Features

- One folder per language
- Comparable implementations

## Tech Stack

- Go
- PHP
- Python

## Getting Started

```bash
git clone https://github.com/ghostland-dev/language-performance-comparisons.git
cd language-performance-comparisons
```
